## Scientific Presentation Principles (MANDATORY)

### Content Fidelity Over Visual Minimalism
- NEVER silently drop quantitative data to fit a layout.
  If the source says "accuracy 94.2%, F1 0.935", ALL numbers MUST appear.
- NEVER paraphrase away precision.
  "p < 0.001" must NOT become "statistically significant".
  "3×10⁻⁵ learning rate with cosine annealing" must NOT become "standard training".
- Use data-dense slide layouts (metrics, tables) when the content demands it.

### Figure Integrity
- NEVER crop scientific figures. Axes, legends, scale bars carry data.
- Always preserve original aspect ratio.
- Prefer whitespace around figures over distortion.

### Structural Guidelines
- Title slide: first slide, dark background.
- Conclusion/Takeaways: last content slide, dark background.
- Spend 40-50% of slides on results.
- Vary slide types: mix content, content_figure, metrics, table layouts.
  Avoid repeating the same bullet-point layout for every slide.
- Introduction → 1-3 slides. Extract core problem + 1-2 motivating examples.
- Methods → 1-3 slides. Flowchart/architecture > bullet lists.
- Results → 40-50% of slides. One main figure per slide + 2-3 bullet findings.
- Discussion → 1-2 slides. Compare with prior work, state limitations.
- Conclusion → 1 slide. 3-5 key takeaways in large text.

### Font Size Reference
| Element | Minimum | Preferred |
|---------|---------|-----------|
| Title slide title | 28 pt | 32-36 pt |
| Content slide title | 22 pt | 24-28 pt |
| Body text / bullets | 16 pt | 18-20 pt |
| Table cells | 12 pt | 14 pt |
| Captions | 10 pt | 12 pt |

### Content Compression
- Bullet points should be phrases, not full sentences.
- 3-6 bullets per content slide.
- Each bullet should contain a specific claim or data point.
- Include [Author, Year] citations in context slides.
