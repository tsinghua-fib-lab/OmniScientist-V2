# Support

Community support is provided through repository issues for reproducible bugs, feature proposals,
and documentation problems. Include `omni doctor`, operating system, Python version, installation
method, and a minimal reproduction. Remove secrets and private research data first.

Security and conduct reports must use the private process described in `SECURITY.md` and
`CODE_OF_CONDUCT.md`. The project does not promise commercial support, uptime for third-party
services, or compatibility with undocumented APIs.
