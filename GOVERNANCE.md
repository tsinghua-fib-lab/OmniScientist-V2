# Governance

OmniScientist is maintainer-led. Maintainers review changes, cut releases, manage security reports,
and decide the bundled skill and connector trust set. Decisions favor reproducibility, local-first
storage, portable contracts, and evidence-backed research output.

Routine changes require one maintainer review. Changes to licensing, security boundaries, data
retention, bundled executable skills, or experimental service integrations require explicit
maintainer approval and a documented rationale. Project governance may evolve as the contributor
base grows; material changes are recorded in `CHANGELOG.md`.
